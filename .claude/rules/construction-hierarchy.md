# 工種階層マスタ

## 定義

工種階層マスタは、**設計書の工事費内訳（積算体系）の階層構造**をベースにした写真分類マスタである。

### 積算体系の構造

```
工事費
├── 直接工事費        ← 費目（工種→種別→細別の階層がある）
├── 共通仮設費        ← 費目（モノ・設備・システム）
├── 現場管理費        ← 費目（人的労力・運営コスト）
└── 一般管理費等
```

### 共通仮設費の内訳（モノ・設備寄り）

準備費（測量・整地）、仮設建物費（事務所・倉庫・休憩所）、工事施設費（仮囲い・工事用道路）、
環境安全費（安全看板・消火設備）、動力用水光熱費、屋外整理清掃費、機械器具費、情報システム費

### 現場管理費の内訳（人的労力寄り）

労務管理費、従業員給料手当、施工図等作成費、保険料、租税公課、
法定福利費、福利厚生費、事務用品費、通信交通費、補償費

## 工種階層

設計書の本工事費内訳書に記載される階層:

```
費目（直接工事費）
└── 工種（舗装工、区画線工、...）
    └── 種別（舗装打換え工、路面切削工、...）
        └── 細別（表層工、オーバーレイ工、...）
            └── 備考（舗設状況、転圧状況、...）
                └── (写真区分)
```

- **費目**: 通常は「直接工事費」で区別不要。ただし安全管理写真等は直接工事と関係なく撮られる場合があり、共通仮設費・現場管理費に紐づくことがある
- **工種**: 何の工事か（舗装工、区画線工、構造物撤去工…）
- **種別**: 工種をどんなやり方で実現するかの選択肢（舗装打換え工、路面切削工…）
- **細別**: 種別の中の段階（表層工、上層路盤工…）
- **備考**: 細別の中の段階（舗設状況、転圧状況…）
- **写真区分**: 階層の一部ではない。強いて言えば備考のあとにつく属性

## CSVカラム対応

| CSV列 | 内容 | 例 |
|--------|------|-----|
| 写真区分 | 費目 | 直接工事費 |
| 写真種別 | 写真の種類 | 施工状況写真、品質管理写真、その他 |
| 工種 | 工種 | 舗装工 |
| 種別 | 種別 | 舗装打換え工 |
| 細別 | 細別 | 表層工 |
| 備考 | 備考 | 使用機械 |
| 検索パターン | AI照合用パターン | 温度管理\|到着温度 |

## 具体例：舗装工

```
直接工事費
└── 舗装工                    ← 工種
    ├── 舗装打換え工           ← 種別
    │   ├── 表層工             ← 細別
    │   │   ├── 舗設状況       ← 備考（作業内容）
    │   │   ├── 初期転圧状況
    │   │   └── 施工完了
    │   └── 上層路盤工         ← 細別
    │       ├── 不陸整正状況
    │       └── 転圧状況
    └── 路面切削工             ← 種別
        └── 路面切削           ← 細別
```

## 使用機械の例

使用機械は工種階層の「その他」に分類される（上古閑方式）:

```
直接工事費 / その他 / {工種} / (空) / (空) / 使用機械
```

工種ごとに実際に使用した機械を仕分ける。種別・細別は空。

## よくある間違い

❌ **絶対にやってはいけない**:
```
種別: 表層工      ← 間違い！表層工は細別
細別: 舗設        ← 間違い！舗設は作業内容（備考）
写真区分を階層のトップに置く ← 間違い！写真区分は階層の一部ではない
```

✅ **正しい**:
```
種別: 舗装打換え工
細別: 表層工
```

## 写真種別一覧

| 種別 | 内容 |
|------|------|
| 着手前及び完成写真 | 工事前後 |
| 施工状況写真 | 作業中 |
| 安全管理写真 | 朝礼、KY活動 |
| 使用材料写真 | 材料検収 |
| 品質管理写真 | 温度・密度測定 |
| 出来形管理写真 | 寸法測定 |
| その他 | 使用機械等 |
