# photo-ai-rust Landing Page

このディレクトリには、プロジェクトのランディングページ（マーケティング用Webサイト）が含まれています。

## 構成
- `index.html`: ランディングページ本体
- `screenshots/`: Web UIのスクリーンショット画像

## 更新手順
1. `web/webserver.exe` を起動します。
2. ブラウザで `http://localhost:9998` にアクセスします。
3. `gstack` などのツールを使用してスクリーンショットを撮影し、`screenshots/web-ui.png` を更新します。
4. `index.html` の内容を必要に応じて修正します。
