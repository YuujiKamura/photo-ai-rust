配布パッケージ

用途に合わせて2つのコンポーネントを提供しています。

  • photo-ai-rust CLI: 高速な写真解析エンジン（エンジニア向け）
  • webserver (Web UI): ブラウザで完結するGUIツール。これだけで全機能が使えます。

必要なもの

  • Windows PC (64bit)
  • Gemini API key (Google AI Studioで取得)
  • 解析したい写真フォルダ

デモモード (Demo)

GitHub Pages等で公開されているバージョンです。サーバーなしで動作し、サンプルデータを使用してUIや解析結果のイメージを確認できます。

ローカルモード (Local)

手元のPCで実行する実務用モードです。実際の写真フォルダをスキャンし、AI解析から台帳出力まで全ての工程を実行します。

起動手順

1. GitHub Releases から webserver.exe をダウンロードして任意のフォルダに配置します。

2. webserver.exe をダブルクリックして起動します。

[info] Starting webserver on :9998...

3. ブラウザで以下のURLを開きます。

http://localhost:9998
