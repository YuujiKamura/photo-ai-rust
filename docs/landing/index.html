Quick Start クイックスタート

  1. Download webserver.exe from Releases Releases から webserver.exe をダウンロードします。
  2. Run webserver.exe webserver.exe を実行します。
  3. Open http://localhost:9998 in your browser ブラウザで http://localhost:9998 を開きます。
  4. Select photo folder and analyze 写真フォルダを選択して解析を開始します。
