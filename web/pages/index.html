いまの構成

メイン入口は Go フロントエンドの photo-ai.exe。 解析・帳票生成の本体は Rust の engine 群に分離し、Web UI はローカルサーバーとして運用します。

Go メイン

ユーザー向けの主系CLI。配布、CI、リリースはこの入口を基準に揃えています。

Rust engines (embedded)

タグ付け、解析、PDF、Excel を個別バイナリに分離。Go バイナリに同梱し、エンジンパス解決の可観測性も確保しています。

ローカル Web UI

最新UIは web/ 側。Pages では静的プレビューだけを公開し、実働はローカルサーバーで使います。

使い分け

静的に見せるものと、ローカルで動かすものを分けています。

GitHub Pages

このページです。サーバーなしで見られる静的プレビューです。

  • 製品の入口説明
  • 構成の把握
  • 実務導入前の確認

ローカル Web UI

webserver.exe で起動する実務用画面です。API と端末連携があるため Pages では動きません。

  • 工種マスタ編集
  • 端末ログ確認
  • 解析結果レビュー

Go メイン CLI

photo-ai.exe から engine 群を呼び出して処理します。

  • analyze
  • export pdf / excel
  • pair / completion
注意: `web/` の本体は `/api/*` とローカル terminal / websocket に依存します。 そのため Pages は `web/pages` の静的入口だけを配信し、実働UIはローカル実行に寄せています。
